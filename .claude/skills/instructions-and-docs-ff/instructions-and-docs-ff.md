---
description: Use when writing/editing any `.md` file, agent instructions, skills, docs, evals, or code comment blocks
---

- Follow `instructions-and-docs` Skill
- Keep each file to what its reader needs 80–90% of the times they open it; move the rest to linked files
- After updating a file, update the files that link to it or that it links to wherever they now disagree
- DRY: shared context lives in one file that others link to (e.g. metric/column definitions live in one shared file, not in every team eval)
- Use bullets and line breaks wherever they aid scanning

# Human team files

`*'s Team.md` and `My Team.md` are for the user to read: concise, but full sentences over ultra-compact notation
