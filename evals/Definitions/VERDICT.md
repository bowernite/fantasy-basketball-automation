# VERDICT

Expands `Eval Definitions §VERDICT`.

Objective: **maximise `Σ P(title)` over the seasons we intend to contend** (`CLAUDE.md` §Objective).

For a concrete deal, publish both deltas and judge them against our `SIT` — never fold them into one number:

- **`ΔBASE`** — both sides on the same curve, picks included (`eval-pick`); a swept band wherever `BASE.md` §*Summing across a package* calls for one.
- **`Δw`** — `trade-screen` / `deal_odds` field wins on the actual pieces, both rosters in. Not summed table rows (`Delta w.md`).

The rule, by our `SIT`:

- **Contending: buy wins.** Accept a modestly negative `ΔBASE` for a clearly positive `Δw`. BASE already contains the market's price on this season, so this is a deliberate premium on current production — capped at **modestly** negative, never at "whatever the wins justify". **Never ship large BASE for small wins.**
- **Fringe:** both deltas ≥ ~0, or pass. Wins that don't move title odds aren't worth BASE — check **`ΔP(title) ours`** on the table if `Δw` alone is ambiguous (`Bracket value.md`).
- **Tanking:** `ΔBASE` decides; `Δw` is ~irrelevant.

**A `ΔBASE` band spanning zero is a BASE tie** — read the `SIT` rule above at `ΔBASE` ~0. Never break it on the band's midpoint or width; where `ΔBASE` was the deciding column, improve the deal instead.

**If the verdict flips on how you weigh the two columns, it's a tie.** Report it as a tie and decide on negotiation grounds — deal shape, flags — or improve the deal. Never invent a conversion rate to force a sign.

# Ranking two offers

Score each against the status quo — `ΔBASE` and joint-sim `Δw` per offer — and compare column by column. An offer that wins both columns wins. Split columns → the `SIT` rule above; still split → a tie, reported as one, never broken on narrative.

**Overlapping `ΔBASE` bands do not order** — that column is a tie between the two offers regardless of where their point values sit.
